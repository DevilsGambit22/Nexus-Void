# The Nexus Void — GitHub Sidebar

Upload `index.html` and the `assets` folder to the root of a GitHub Pages repository.

## Included
- Animated orange/violet void theme
- Live Chess.com club member count and member feed
- MCA countdown driven by the next scheduled MCA club match/event start time from Chess.com PubAPI
- Daily match feed
- Vote Chess fallback display
- Owner / Co-Owner profile cards
- Forums, events, announcements and club links
- Transparent ACFA Lady Justice copyright image linked to And Chess For All Official


The MCA timer does not assume a fixed Sunday hour. It searches the club's registered/in-progress match data for an event containing `MCA`, follows its PubAPI match record, reads `start_time`, and counts down to that scheduled time.
